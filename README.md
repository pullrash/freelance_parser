# 🚀 Freelancehunt Job Monitor Bot

Автоматизований Telegram-бот для миттєвого відстеження нових замовлень на біржі **Freelancehunt**. Більше не потрібно оновлювати сторінку кожні 15 хвилин — бот зробить це за вас і надішле сповіщення прямо в месенджер.



## ✨ Особливості
* **Офіційний API v2**: Найнадійніший спосіб отримання даних. Жодних блокувань (403 Forbidden) чи проблем із Cloudflare.
* **GitHub Actions**: Проєкт працює "в хмарі" 24/7 абсолютно безкоштовно. Вам не потрібен власний сервер чи постійно ввімкнений комп'ютер.
* **Розумні сповіщення**: Бот відстежує останній оброблений ID, тому ви отримуєте лише нові, унікальні замовлення.
* **Легке налаштування**: Гнучка фільтрація за категоріями та навичками через параметри запиту.

## 🛠 Технологічний стек
* **Мова:** Python 3.10+
* **Бібліотеки:** `requests` (для роботи з API та Telegram)
* **Автоматизація:** GitHub Actions (Scheduled Workflows)
* **Збереження стану:** Текстова база даних (`last_id.txt`)

---

## 🚀 Як це працює
1. **Trigger**: GitHub Actions запускає скрипт кожні 15 хвилин за розкладом (cron).
2. **Fetch**: Скрипт звертається до офіційного API Freelancehunt, використовуючи ваш персональний токен.
3. **Filter**: Програма порівнює ID отриманих проєктів із останнім збереженим значенням.
4. **Notify**: Якщо з'явилися нові замовлення, бот формує повідомлення та надсилає його в Telegram.
5. **Update**: Новий ID останнього проєкту зберігається в репозиторій для наступного циклу перевірки.

## ⚙️ Налаштування (Installation)

### 1. Підготовка ключів
* **Telegram**: Створіть бота в [@BotFather](https://t.me/botfather) та отримайте `TOKEN`. Дізнайтеся свій `CHAT_ID` через [@userinfobot](https://t.me/userinfobot).
* **Freelancehunt**: Згенеруйте **Personal Access Token** у розділі [Налаштування API](https://freelancehunt.com/my/api) (версія v2).

### 2. Секрети GitHub
Перейдіть у свій репозиторій: `Settings` -> `Secrets and variables` -> `Actions` та додайте три секрети:
1. `API_TOKEN` — ваш токен Freelancehunt.
2. `TOKEN` — токен Telegram-бота.
3. `CHAT_ID` — ваш особистий ID у Telegram.

### 3. Структура проєкту
```text
├── .github/workflows/
│   └── monitor.yml      # Налаштування розкладу запусків (Cron)
├── main.py              # Основна логіка бота
├── requirements.txt     # Необхідні бібліотеки (requests)
├── last_id.txt          # Файл збереження стану (ID останнього проєкту)
└── README.md            # Документація проєкту
